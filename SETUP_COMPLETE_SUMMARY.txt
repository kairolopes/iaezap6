================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Table does not exist" error
Solution: Database migrations not completed. Go back to Step 1.
Action: Execute migrations/001_complete_migration_bundle.sql in SQL Editor

Problem: "Could not find the table 'public.companies' in the schema cache"
Solution: Supabase schema cache needs refresh
Action: Wait a few seconds and try again, or restart the Node.js process

Problem: "Failed to create master company"
Solution: Master company already exists from previous run
Action: Run migration script again - it will use existing company

Problem: "Password hash generation failed"
Solution: Bcrypt module not installed or corrupted
Action: Run: npm install bcrypt

Problem: Connection timeout
Solution: Supabase credentials incorrect or project offline
Action: Verify .env.local credentials, check Supabase dashboard status

Problem: "Master user not found" after creation
Solution: User wasn't actually inserted (check for SQL errors)
Action: Check Supabase dashboard audit logs, retry Step 2
